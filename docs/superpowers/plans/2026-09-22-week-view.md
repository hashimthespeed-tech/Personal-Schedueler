# Week View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Monday–Sunday schedule view with direct five-tab navigation and a safe task edit sheet backed by the same task rows as Today.

**Architecture:** A pure `core/week.ts` module owns week boundaries and presentation ordering. A read-only week API assembles seven generated day frames plus one range query of scheduled tasks. Existing task placement logic gains an edit helper that excludes only the edited task, while the task API recomputes every option before an atomic resize or move. The client renders one selected day and calls those APIs; it owns no duplicate schedule state.

**Tech Stack:** Next.js App Router, React, TypeScript, Luxon, Drizzle ORM/PostgreSQL, Zod, Vitest, Playwright CLI.
